# Локальний бот-аналітик для бінарних опцій (FOREX)

Бот аналізує валютні пари (Євро/Долар, Фунт/Долар, Долар/Йена тощо) і видає сигнал: **CALL (вгору/покупка)**, **PUT (вниз/продаж)** або **ЧЕКАТИ**.

## Файли
- `bot.py` — аналіз валютних пар через Yahoo Finance (FOREX; є затримка даних)
- `bot_realtime.py` — реальний час через Binance WebSocket (тільки крипта, без затримки)
- `market_analyzer.py` — завантаження даних та індикатори
- `strategy.py` — логіка сигналів
- `config.py` — налаштування (тикер, інтервал, пороги)
- `requirements.txt` — залежності

## Встановлення (macOS)

```bash
cd "/Users/maxshypilkin/Desktop/binary_bot"
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

### З валютними парами FOREX (EUR/USD, GBP/USD, USD/JPY і т.д.)
```bash
python bot.py
```
Програма запропонує оберути пару зі списку та інтервал свічки, а потім відразу виведе сигнал.

### З Binance в реальному чаті (тільки крипта: BTC, ETH і т.д.)
```bash
python bot_realtime.py
```

## ⚠️ Важливе попередження
Цей код — **виключно освітній приклад**. Він не є фінансовою порадою.
Бінарні опції мають високий ризик втрати коштів. Співвідношення ціни Yahoo Finance і ціни брокера може відрізнятися.
Тестуй стратегію на демо-рахунку перед використанням реальних коштів.
